Challenge sets: finishing a set without going broke

SBCs made of several challenges, the reward for the full set, and the order to do the challenges in.

Updated 11 November 2026 · 2 min read

A set groups several challenges, each with its own reward, plus an extra reward when they're all done. League sets and match sets are typical examples.

Work out the whole set

A set should be judged as a whole: the cost of all the remaining challenges on one side, each challenge's reward plus the final reward on the other. A set can be worth it even if one of its challenges, on its own, isn't.

In what order?

  1. Start with the hardest challenge for your club: if you can't do it, there's no point giving away cards in the others.
  2. Then do the ones that need cards you have lots of.
  3. Keep the cheapest challenges for last: they're what you use to wrap up the set.

The half-finished set trap

A set abandoned halfway is often the worst option: you've paid part of the cost without getting the final reward. Before you start, check that you can see it through, with your cards or with purchases you're happy to make.

Tip Check the end date: a set that ends soon comes before permanent SBCs.

Example: a four-challenge league set

A set asks for four squads, each with players from a given league, and gives a big pack at the end. Three challenges are easy with your club. The fourth requires a high team rating and players from a league where you have almost nothing. If you do the three easy ones first, you may get stuck on the fourth, with fodder already used up.

Starting with the hardest one tells you right away whether the set is doable. If that challenge means buying cards, you can decide with full knowledge, before committing to the others.

Frequently asked questions

Do I get the rewards of every challenge? Yes: each challenge has its reward, plus the one for the full set once they're all done.

Can a set expire half done? Yes. The challenges already done stay done, but the final reward is lost.

In Squadoro

A set appears as a large tile with its progress (“1/4 done”) and its total gain or cost. Tap it to see each numbered challenge with its cost, and the “Do challenge” button takes you to the next one.
