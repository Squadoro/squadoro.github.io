Les sets de défis : finir un set sans se ruiner

Les DCE en plusieurs défis, la récompense du set complet et l'ordre dans lequel faire les défis.

Mis à jour le 11 novembre 2026 · 2 min de lecture

Un set regroupe plusieurs défis, chacun avec sa propre récompense, et une récompense supplémentaire quand tous sont terminés. Les sets de ligues et de matchs en sont des exemples typiques.

Calculer le set en entier

Un set se juge sur l'ensemble : coût de tous les défis restants d'un côté, récompenses de chaque défi plus récompense finale de l'autre. Un set peut être rentable même si un de ses défis, pris seul, ne l'est pas.

Dans quel ordre ?

  1. Commence par le défi le plus difficile pour ton club : si tu ne peux pas le faire, inutile de sacrifier des cartes dans les autres.
  2. Fais ensuite ceux qui demandent des cartes dont tu as beaucoup.
  3. Garde pour la fin les défis les moins chers : ils servent à boucler le set.

Le piège du set à moitié fini

Un set abandonné en route est souvent la pire option : tu as payé une partie du coût sans la récompense finale. Avant de commencer, vérifie que tu peux aller au bout, avec tes cartes ou avec des achats que tu acceptes.

Astuce Vérifie la date de fin : un set qui expire bientôt passe avant les DCE permanents.

Exemple : un set de ligue en quatre défis

Un set demande quatre équipes, chacune avec des joueurs d'une ligue donnée, et offre un grand pack à la fin. Trois défis sont faciles avec ton club. Le quatrième demande une note d'équipe élevée et des joueurs d'une ligue où tu n'as presque rien. Si tu fais d'abord les trois faciles, tu risques de rester bloqué sur le quatrième, avec du fourrage déjà consommé.

En commençant par le plus difficile, tu sais tout de suite si le set est faisable. Si ce défi te demande d'acheter des cartes, tu peux décider en connaissance de cause, avant d'avoir engagé les autres.

Questions fréquentes

Les récompenses de chaque défi sont-elles cumulées ? Oui : chaque défi a sa récompense, plus celle du set complet quand tous sont faits.

Un set peut-il expirer à moitié fait ? Oui. Les défis déjà faits restent acquis, mais la récompense finale est perdue.

Dans Squadoro

Un set apparaît comme une grande tuile avec sa progression (« 1 / 4 faits ») et son gain ou son coût total. En la touchant, tu vois chaque défi numéroté avec son coût, et le bouton « Faire le défi » t'emmène au suivant.
